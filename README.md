# 节点象棋 NodeXQ

安卓端中国象棋应用，主打 **多引擎对弈 + 专业级复盘分析**。

不只是跟电脑下棋，更关键的是下完之后能帮你复盘：哪一步走亏了、整盘棋水平打几分、错招都给你标出来。软件自带三个强力象棋引擎，从入门到顶尖水平都能找到合适的对手。

- 语言：Java
- 包名：`com.tyl.xiangqi.ndxq`
- 安装包标识：`com.tyl.xiangqi.nodechess`
- 架构：仅 `arm64-v8a`
- 最低系统：Android 6.0（API 23）

---

## 难度是经过校准的

- **每一档都经过校准**，难度名和真实棋力基本对得上——写着「特级大师」，就是真人特级大师的水平，不会出现实际棋力远超同级别人类棋手的情况。
- **采用锁节点的方式压制引擎棋力**：不管你用什么配置的手机，都能体会到同样的棋力，不会因为手机性能高，人机就跟着变强。

## 功能

### 对弈

- **13 档人机难度**，从最低的「独孤求胜」到最高的「青云」：
  独孤求胜、略知一二、雾里看花、初悟棋道、初露锋芒、棋摊中坚、街头霸王、县镇好手、市县好手、业余顶尖、特级大师、天下无敌、青云。
- **开局库**：对局前几回合走开局库，之后交给引擎自行搜索，开局不会走得莫名其妙。
- **提和思考**：由引擎代为判断局面。
- **立即出招**：对局中可让电脑马上走棋，不用等。
- **推荐着法箭头**：用红蓝分色箭头画在棋盘上，第三、四步用浅色续着。

### 分析

- **放大镜分析**：对当前局面做 MultiPV 多路分析，可设深度、节点数或时间，实时显示候选着法评分。
- **局势图**：每步限时快速打分，画成走势曲线，一眼看出优势是在哪一步丢掉的。
- **对局报告**：整盘自动生成百分制评分，按开局、中局、残局分段聚合，错招单独标出，温度参数可调后重算。
- **错题本**：把错招存下来，随时调出错题推演，针对弱点反复练。
- **重新打分**：对已有棋谱逐手重新评估，可只给当前分支打分，也可遍历全部分支。

### 评测与等级分

- **评测模式 22 档**，用等级分衡量实力，初始分 500。
- 连胜会加速加分（第 1~4 胜 K=32，第 5~9 胜 K=64，第 10 胜起 K=108 封顶），连败、和棋或无效评测则清零加速状态。
- 玩家等级分按 **Elo K=32** 独立结算，与「几胜几和几负」的战绩分开记账。

### 棋谱

- 支持 **XQF** 与 **PGN** 读写，PGN 用 GBK 写出以兼容鲨鱼象棋。
- XQF 读取能自动识别行棋方，避免部分第三方软件把黑方首着标成红方导致只读半盘。
- 支持任意分支、变招、注释，分支自动标注 A/B/C 线路编号，分支标签随 XQF 一起保存。

### 外观

- 默认皮肤已内置于 APK，首次安装无需复制任何文件。
- 支持**外置皮肤**：放到手机 `/storage/emulated/0/nodexq/pic/<皮肤名>/` 即可。
- **动态网格校准**：拖动四个黄色角点对齐棋子落点，方向键微调，按住网格内部可整体平移，棋子大小可在校准页实时预览调整。
- 全局高亮色、红黑箭头配色、局势图线条颜色、全局底色均可自定义，支持 HSV 色盘选取与六位 RGB 直接输入，可一键恢复默认。

## 从源码编译

> **本仓库只包含源码。** 引擎库与开局库因体积和许可原因未随仓库分发，编译前需自行补齐。

### 1. 环境要求

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Gradle | 8.7（仓库已带 wrapper） |
| Android Gradle Plugin | 8.6.1 |
| compileSdk / targetSdk | 35 |
| minSdk | 23 |
| ABI | 仅 `arm64-v8a` |

### 2. 补齐引擎库（必需）

引擎以 `.so` 形式打包进 APK，安装后由系统提取到 `nativeLibraryDir`，运行时用 `ProcessBuilder` 拉起（Android 10 之后不能再执行 `filesDir` 里的二进制，故采用此方案）。

把以下文件放入 `app/src/main/pikafish/arm64-v8a/`：

| 文件名 | 对应引擎 | 说明 | 来源 |
|---|---|---|---|
| `lib131.so` | **131** | 皮卡鱼，棋力最强，用于最高难度与分析 | <https://github.com/official-pikafish/Pikafish> |
| `pikafish.nnue.so` | — | 131 使用的 NNUE 权重（打包时会自动改名为 `libpikafish.nnue.so`） | 随皮卡鱼一同发布 |
| `libHCE.so` | **HCE** | 皮卡鱼传统评估版（无神经网络），用于低难度档 | <https://github.com/skystarspython/Pikafish-HCE> |
| `libduf.so` | **duf** | Duffish3，NNUE 已完整内嵌在二进制里，无需外置权重 | <https://github.com/lxsgx23/Duffish> |

> 另有一个历史遗留文件 `libqsll-static-exec.so`，当前源码已无引用，可不提供。

这三个引擎均为 **arm64-v8a** 版本，需自行用 Android NDK 交叉编译各引擎源码得到。

### 3. 补齐开局库（可选）

把开局库放到 `app/src/main/assets/books/rp/book.obk`。

未提供时应用会跳过开局库加载，**不影响编译、引擎启动和基本对弈**。

### 4. 编译

用 Android Studio 打开本项目后走 `Build → Generate Signed Bundle / APK`（选 APK，构建变体选 release），或命令行：

```bash
./gradlew assembleRelease
```

## 项目结构

```
app/src/main/
├── java/com/tyl/xiangqi/ndxq/
│   ├── MainActivity.java            主界面与入口
│   ├── core/                        棋盘规则、着法、棋谱读写（XQF / PGN）、报告评分
│   ├── engine/                      引擎启动与 UCI 通信
│   ├── ui/                          棋盘绘制、皮肤、局势图、难度条等自定义 View
│   ├── storage/                     棋谱与最近对局的读写
│   └── *Controller.java             会话、评分、皮肤、分析、编辑、分支等功能控制器
├── res/
│   ├── drawable-nodpi/              内置默认皮肤（board + 14 张棋子图）
│   ├── raw/                         落子与将军音效
│   └── values/                      字符串与样式
├── assets/books/rp/                 开局库位置
└── pikafish/arm64-v8a/              引擎库位置（本仓库不包含）
```

`CHANGELOG.md` 记录了各版本的详细改动与踩坑总结，`tools/` 下是各版本的校验脚本。
